🚨 应急疏散快照

输入事件时刻并勾选一个或多个出口区域：按当前校验模式的实际路线还原每位演员当时的位置（区域等待 / 停留 / 通道行进中）。 位于通道者先按原方向走完剩余路程，再从到达区域按事件时刻之后的封闭时段计算到任一出口的最早疏散路线；位于区域者从事件时刻直接计算； 因不可达链无法确定位置的演员单独标为位置未知，不做猜测。结果按最晚撤离优先排序，导出的 Markdown 报告会追加同一快照。

🔗 跨演员口令依赖

在两条口令之间维护「前置口令完成（当前模式下实际到达 + 停留时长）后至少等待 N 秒，后置口令才可实际出发」的有向约束（两条口令可属于不同演员）。 保存前会检查整张依赖图，成环时拒绝写入并提示闭环口令链。下方结果按当前校验模式即时重算： ✅ 满足、❌ 违约（附相差秒数）、❓ 无法判定（任一端口令不可达或无实际出发时刻）。删除口令会自动清理相关依赖。

📥 排练数据 CSV 导入

下载模板填写排练口令后上传：系统按「姓名 + 角色」复用演员（无匹配则自动新建，同名同角色不唯一会报错）、 按区域名精确解析目标区域，逐行校验时间 / 停留格式、未知 / 重名区域、文件内重复与现有口令冲突。 存在错误行时禁止提交；预览会生成带数据版本的导入计划，提交时若底库已被修改将要求重新预览。 时间支持秒数（如 90）或 mm:ss（如 01:30），停留秒数为 0～600 的整数（留空按 0）。

🎬 现场走位复盘

上传演出实际走位记录（UTF-8 CSV：演员姓名、角色、实际时刻、实际区域）：系统仅解析现有演员与区域， 未知或歧义（同名同角色演员不唯一、重名区域）值与错误时刻逐行报错、不参与对齐。 随后按演员将实际记录与计划口令做保持先后顺序的一对一最优对齐：配对成本 = 时刻差绝对值 + 区域不符 300， 每个漏执行口令或多余记录计 180；成本相同时先取配对数多者，再取实际记录行号序列字典序较小者，同一记录不重复匹配。 展示每位演员的配对、时间偏差、区域偏差及漏项 / 多项汇总，可下载本次复盘 Markdown。上传分析为只读操作，不会改写任何走位数据。
